# CMOS-inverter-LTspiec

# CMOS Inverter Simulation in LTSpice

## 🧠 Overview
This project demonstrates a basic CMOS inverter simulated using LTSpice. It includes:
- Schematic of a CMOS inverter
- Transient simulation for voltage transfer characteristics
- Waveform showing logic inversion and switching delay

## 🔧 Tools Used
- **LTSpice XVII** (Analog Devices)

## 📊 Simulation Results
- Shows clear inverting behavior
- Includes waveform of input vs output
- Can observe delay and VTC behavior
